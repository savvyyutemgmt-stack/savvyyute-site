# Savvy Yute Management website

Live: https://savvyyute.netlify.app
Admin: https://savvyyute.netlify.app/admin/

- Page text and design settings live in `content/` (one file per admin section), edited through the admin panel (Decap CMS).
- Edits are saved as drafts with a Netlify preview link; "Publish" puts them live.
- `index.html` holds the design and renders whatever is in `content.json`.

## What the admin panel controls
- **Design:** logo, all colours, heading and body fonts, heading case and size, body text size, scrolling titles on/off
- **Layout:** menu links, show/hide each section, section titles, the release route graphic
- **Content:** SEO, hero, services, work cards (with optional photos), figures, artists, events, Hip Hop Cabin, partner label, contact
